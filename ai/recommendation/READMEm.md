# ShopSense - Recommendation System

جزء الـ Recommendation من مشروع ShopSense، وهو متجر إلكتروني بيستخدم 3 AI models.

الموديل عبارة عن item-based collaborative filtering، شغال كـ Flask API لوحده على بورت 5001. متدرب على RetailRocket dataset (أكتر من 2.7 مليون event)، والنتيجة اللي طلعت Hit Rate@5 = 0.2305.

الكود وخطوات التشغيل والتفاصيل كاملة موجودة جوه [ai/recommendation](./ai/recommendation)
